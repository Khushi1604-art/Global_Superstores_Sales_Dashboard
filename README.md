# Global_Superstores_Sales_Dashboard
Interactive Power BI dashboard analyzing Global Superstore sales performance and product insights

This project is an interactive sales analytics dashboard built using Microsoft Power BI.
The dashboard analyzes the Global Superstore dataset to understand sales performance, product profitability, regional demand, and customer segments.

The dataset contains 50,000+ sales records including order details, product categories, regions, customer segments, sales, profit, and shipping information.

The goal of this project is to convert raw business data into meaningful insights through interactive visualizations.
